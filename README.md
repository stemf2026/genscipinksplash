# PinkSplash — Dishwashing Liquid Website

Official project website for **PinkSplash**, a modified DIY dishwashing liquid developed by **Group 2 • STEM-F**.

**Brand:** Hugasé  
**Tagline:** *Dishwashing Liquid of your dream coming true.*

---

## About the Project

PinkSplash is a General Science / STEM project that starts from a basic DIY dishwashing liquid and improves it to be:

- Safer and more skin-friendly
- More effective at grease removal
- Richer in foam
- Eco-conscious and more enjoyable to use
- Visually appealing with a signature pink look and watermelon scent

### Key Ingredients
- Sodium Laureth Sulfate (SLES)
- CAPB (Cocamidopropyl Betaine)
- Citric Acid
- Glycerin
- Salt (Sodium Chloride)
- Pink Colorant
- Watermelon Fragrance Oil

## How to View Locally

1. Download or clone this repository.
2. Open `index.html` in any modern browser  
   **or** use a local server:

```bash
# Python
python -m http.server 8000

# Node (if you have npx)
npx serve .
```

Then visit `http://localhost:8000`

---

## Deploy on GitHub Pages

1. Create a new repository on GitHub (e.g. `pinksplash` or `PinkSplash-website`).
2. Upload all files in this folder to the repository root (or push via Git).
3. Go to **Settings → Pages**.
4. Under **Source**, select the branch (`main`) and folder `/ (root)`.
5. Save. Your site will be available at:  
   `https://<your-username>.github.io/<repo-name>/`
